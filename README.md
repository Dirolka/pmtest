# Практика — Project Management

Запустите `main.py` кнопкой Run в PyCharm. Откроется http://127.0.0.1:8000.
Зависимости устанавливать не нужно: сервер использует стандартную библиотеку Python.
Если порт занят, передайте `--port 8001`. Для запуска без открытия браузера — `--no-browser`.
Остановка сервера: кнопка Stop в PyCharm или Ctrl+C.

## Возможности

- 164 вопроса с пятью вариантами ответа, извлечённые из 79 фотографий.
- Повторы снимков и одинаковые вопросы объединены. Ситуации с разными условиями сохранены отдельно.
- Все вопросы, только теория или ситуации; 20, 50 или все вопросы; перемешивание.
- Режим обучения с немедленной проверкой и режим теста с проверкой в конце.
- Навигация, пропуск вопросов, сохранение прогресса в браузере, повтор ошибок, экспорт ответов.
- Исходные фотографии рядом с вопросами и отдельная галерея всех 79 снимков.

## Данные и ограничения

`data/questions.json` — редактируемый банк. `answer` — индекс ответа от 0 до 4.
Официального ключа среди фотографий нет. Ключ составлен по смыслу вопросов для самостоятельной подготовки, он не является официальным ключом преподавателя.
Часть снимков размыта и обрезана; неполные вопросы не восстановлены предположениями. Все оригиналы сохранены в `picture/`.
`data/ocr.json` содержит исходное распознавание с координатами строк; `data/rejected.json` — неполные результаты распознавания, включая повторы.

После изменения банка обновите браузерную копию (нужен Node.js):

```sh
node -e "const fs=require('fs');fs.writeFileSync('static/questions.js','window.QUESTIONS = '+fs.readFileSync('data/questions.json','utf8')+';\\n')"
```

Сайт работает локально. Ответы сохраняются только в localStorage этого браузера.

## Дополнение из файла `add`

На главной странице появилась кнопка «Открыть дополнение»: 77 новых карточек с короткими подсказками и ответами из присланного ключа. Полные формулировки и неправильные варианты A–E в этом файле отсутствуют, поэтому дополнение использует письменный ответ и самопроверку. Есть фильтры по варианту/разделу, перемешивание, сохранение черновиков и оценок, повтор ошибок.

Обработаны все 250 строк: 163 сопоставлены с существующими вопросами, 77 добавлены, 3 объединены с другими новыми карточками, 7 оставлены с исходной пометкой о неподтверждённых данных. В основном тесте исправлен ответ на вопрос о неидентифицированных/неавторизованных задачах: The unallocated budget.

- `data/supplement.json` — новые карточки; `static/supplement.js` — браузерная копия.
- `data/add-audit.json` — результат сопоставления каждой из 250 строк.
- `static/add-source.txt` — копия присланного ключа, доступная на странице дополнения.
- `node tools/import-add.cjs` — повторный импорт текущего файла add. Привязки строк к основному банку проверены для этого файла; при замене add другим документом сначала обновите привязки в скрипте.
- Проверки: `node tests/quiz.cjs` и `node tests/supplement.cjs`.

Ключ из `add` — присланный пользователем источник. Документы, упомянутые внутри него, отдельно не предоставлены и не проверялись.
